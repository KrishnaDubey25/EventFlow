# EventFlow Professional UI + Indoor 3D Update

- Landing palette standardized to dark navy, beige and white.
- Navbar and footer converted to dark navy premium surfaces.
- Bright blue landing accents replaced with beige/gold neutrals.
- Indoor 3D engine remains fully local: no LingBot, Colab, Cloudflare or API key.
- Reference photos/videos are accepted in the Venue Builder.
- A frame from uploaded video or uploaded image is sampled locally to tune the 3D palette.
- Event type selects a professional architecture template:
  - stadium -> tiered bowl, concourse, roof, pitch, portals
  - concert -> stage, truss rig, audience lanes, tiered stands, portals
  - expo/conference -> pavilion hall, booths, central aisle, glass shell, portals
- Attendee and volunteer avatars use a slimmer modern human silhouette.
- Routes are template-aware and use subdued premium lighting.
- Organizer can still drag/place facilities and volunteer points.

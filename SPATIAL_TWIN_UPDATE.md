# EventFlow Video-Derived Spatial Twin

- Landing page files were not modified in this update.
- Organizer can upload venue walkthrough video/photos.
- EventFlow extracts key frames locally in the browser.
- Key frames are rendered as textured displacement meshes for an interactive 2.5D spatial-depth twin.
- No external API key, Colab session, tunnel, or GPU backend is required for this lightweight demo flow.
- Spatial twin frames are stored in IndexedDB for the current browser and can be reloaded by the attendee view for the same event/name key.
- Indoor route, professional guide avatar, venue labels and operational overlays are rendered on top of the twin.
- This is a lightweight navigation/demo visualization, not survey-grade photogrammetry or metric-accurate reconstruction.

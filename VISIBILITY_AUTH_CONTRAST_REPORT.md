# EventFlow Visibility + Authentication Contrast Pass

- Preserved existing features, routes, workflows and landing page.
- Added a surface-aware contrast engine for authenticated screens. Dark/navy surfaces use high-contrast light foregrounds; nested beige/light cards automatically restore dark foregrounds.
- Covered legacy black/brown/gray text utilities that could become unreadable on navy surfaces.
- Kept form input, selected option, placeholder, focus and autofill values readable.
- Restyled only the authentication shell/card to the EventFlow navy + beige + gold visual system.
- Normalized old indigo/teal auth accents into the same 3-color family.

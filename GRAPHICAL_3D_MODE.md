# EventFlow Graphical 3D Venue Twin

This build replaces experimental neural/depth reconstruction with a stable, self-contained graphical 3D venue engine.

- No API key, Colab, Cloudflare, GPU backend, or external reconstruction service.
- Organizer can upload venue photos/video as reference media before generating the venue twin.
- The generated scene is a polished architectural navigation model, not a claim of photogrammetric reconstruction.
- Event type is inferred from the event name (stadium/sports, concert/music, expo/conference) to select a suitable professional venue layout.
- Scene includes gates, zones, facilities, route visualization, attendee marker, volunteers, orbit/zoom/pan, and clickable POIs.
- Landing page files were not modified in this pass.

# Form Visibility Fix

This pass changes only form readability inside the authenticated EventFlow app.

Fixed globally:
- typed values in text/number/email/password/url/date/time fields
- textarea content
- select selected values and dropdown options
- placeholders
- disabled controls
- browser autofill text/background
- focus states and caret visibility
- file input text/button
- form label contrast on both dark and light surfaces

The existing EventFlow palette and workflows were not changed.

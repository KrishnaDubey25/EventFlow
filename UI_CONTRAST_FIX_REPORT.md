# EventFlow Internal UI Contrast Fix

- Landing page was not changed.
- Internal app surfaces use deep navy instead of pure black.
- Dark-on-dark text combinations are overridden to high-contrast off-white.
- Secondary text uses a brighter steel-blue gray for readability.
- Primary interaction accent is restrained charging blue.
- Beige is used only as a secondary accent/badge/button tone.
- Light cards inside Organizer/Operator/Attendee screens are normalized to dark navy surfaces.
- Borders, inputs, focus states, semantic alerts, sidebars, and map containers were normalized.
- Internal headings now use Plus Jakarta Sans instead of the landing display font for a more professional dashboard look.
- Organizer sidebar active state now uses blue rather than gold-heavy styling.
